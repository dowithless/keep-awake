# 截图语言代码与中文名称对照

上传时以 **App Store Connect 的语言名称**为准。文件夹代码表示本地化语言，部分还包含国家代码；并非每个文件夹都只对应一个国家。

以下按文件夹名称排序，方便与 Finder 中的目录逐项核对。

| 截图文件夹代码 | 商店页面应选择的中文语言名称 | 国家／地区提示（便于识别） |
| --- | --- | --- |
| [de-DE](de-DE/) | **德语** | 德国 |
| [en-US](en-US/) | **英语（美国）** | 美国 |
| [es-ES](es-ES/) | **西班牙语（西班牙）** | 西班牙 |
| [fr-FR](fr-FR/) | **法语** | 法国 |
| [it](it/) | **意大利语** | 意大利 |
| [ja](ja/) | **日语** | 日本 |
| [ko](ko/) | **韩语** | 韩国 |
| [pt-BR](pt-BR/) | **葡萄牙语（巴西）** | 巴西 |
| [ru](ru/) | **俄语** | 俄罗斯 |
| [zh-Hans](zh-Hans/) | **简体中文** | 中国大陆、新加坡等使用简体字的地区 |
| [zh-Hant](zh-Hant/) | **繁体中文** | 台湾、香港、澳门等使用繁体字的地区 |

国家／地区提示仅帮助识别语言，不限定截图的展示范围；简体中文和繁体中文分别表示文字体系。

## 容易选错的项目

- `pt-BR` 是**巴西**葡萄牙语，对应“葡萄牙语（巴西）”。
- `es-ES` 是**西班牙**西班牙语，对应“西班牙语（西班牙）”。
- `en-US` 是**美国**英语，对应“英语（美国）”。

## 上传顺序

先在页面右上角选择本表对应的语言，再打开同名文件夹，按以下顺序上传五张 PNG：

1. `01-keep-awake.png`：核心用途，一键保持唤醒。
2. `02-display-sleep.png`：屏幕与系统独立控制。
3. `03-manual-sleep.png`：手动休眠，自动结束防休眠。
4. `04-simple.png`：简洁、小巧的使用体验。
5. `05-open-source.png`：开源与透明。
